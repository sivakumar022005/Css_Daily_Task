# 📊 Admin Dashboard

A modern and responsive **Admin Dashboard** created using **HTML and CSS**.  
This project provides a clean dashboard interface with statistics, sales overview, user management, and navigation sections.

## 🚀 Features

- 📌 Responsive Sidebar Navigation
- 📊 Statistics Cards
- 👥 Total Users Overview
- 💰 Sales Overview
- 📦 Order Statistics
- 🛍️ Product Statistics
- 📈 Sales Chart
- 👤 Recent Users Table
- ⚡ Quick Statistics
- 🎨 Clean and Modern UI
- 📱 Responsive Design
- 🖱️ Hover Effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Media Queries
