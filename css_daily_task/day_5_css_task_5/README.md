# 🎨 Animated CSS Gallery

A beautiful and responsive image gallery created using **HTML and CSS**.  
The project includes smooth hover animations, image zoom effects, overlay captions, and a responsive grid layout.

## 🌟 Features

- ✨ Modern dark UI
- 🖼️ Responsive image gallery
- 🔍 Image zoom animation on hover
- 🎬 Smooth overlay animations
- 💡 CSS hover effects
- 🌈 Neon glow effect
- 📱 Fully responsive design
- 🎞️ CSS fade-in animation
- 🚫 No JavaScript required

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Transitions
- CSS Animations
- Media Queries
