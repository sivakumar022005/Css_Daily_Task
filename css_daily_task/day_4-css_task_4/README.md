# NAB Bank Website

A simple **NAB Bank website clone** created using **HTML and CSS**.
This project is designed to practice webpage structure, styling, navigation, cards, buttons, dropdowns and responsive layout concepts.

## 📌 Project Overview

This project recreates the basic layout and visual structure of the **National Australia Bank (NAB)** website.

It includes:

* Navigation bar
* NAB logo
* Personal, Business, Corporate and About Us navigation
* Login button
* Credit card promotional section
* Popular banking solutions
* Home loan and savings sections
* Business banking section
* Travel banking section
* Footer with quick links
* Social media links

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts – Poppins

## ✨ Features

### Navigation Bar

The website contains a navigation bar with:

* NAB Logo
* Personal
* Business
* Corporate
* About Us
* Help and Support
* Login Button

### Credit Card Section

A promotional section is included for NAB Qantas Rewards Signature Card with a **Find out more** button.

### Popular Banking Solutions

The project contains dropdown menus for:

* Everyday Banking
* Credit Cards
* Home Loans
* Business Banking

### Banking Services

Different sections are included for:

* Refinancing
* Savings Accounts
* Business Banking
* Travel Banking

### Footer

The footer contains:

* Quick Links
* Policies and Terms
* Security and Fraud
* Contact Us
* Feedback
* Accessibility
* Social Media Links
* NAB disclaimer information

## 🚀 How to Run

1. Download or clone this repository.

2. Open the project folder.

3. Make sure all images are available inside the `img` folder.

4. Open `index.html` in any web browser.

That's it! 🎉
