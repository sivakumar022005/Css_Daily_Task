🍽️ La Bella Restaurant Website

A modern and responsive restaurant website built using HTML5 and CSS3. The website features a luxury restaurant design with a beautiful hero section, menu, special offers, gallery, and reservation form.

Responsive restaurant website
Modern luxury design
Full-screen hero section
Navigation menu
About restaurant section
Food menu section
Special offer section
Restaurant image gallery
Table reservation form
Contact information
Responsive design for mobile, tablet, and desktop
Smooth scrolling
Hover animations and effects

📋 Website Sections
1. Home

A large hero section introducing La Bella Restaurant with buttons for viewing the menu and booking a table.

2. About

Information about the restaurant, its food, and dining experience.

3. Menu

Displays popular dishes with descriptions and prices.

4. Special Offers

Highlights a special weekend family dinner offer.

5. Gallery

A collection of restaurant and food images.

6. Contact & Reservation

Includes restaurant contact details and a table reservation form.
