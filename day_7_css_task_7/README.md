# 🎬 MovieFlix - Netflix Style Movie Website

MovieFlix is a Netflix-inspired movie streaming website created using **HTML and CSS**.  
This project is designed to practice modern web design concepts such as Flexbox, responsive layouts, hover effects, movie cards, and hero sections.

## 🚀 Features

- 🏠 Netflix-style homepage
- 🎬 Hero banner section
- 🍿 Trending movies section
- 🔥 Popular movies section
- 📂 Movie categories
- 🔐 Login button UI
- 📱 Responsive design
- 🎨 Modern dark theme
- ✨ Movie card hover effects
- 📜 Footer section

## 🛠️ Technologies Used

- HTML5
- CSS3
